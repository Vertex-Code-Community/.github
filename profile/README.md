## ⚙️ Engineering Workflow

We care about how software is built, not only what is built.

Our development process includes:

```mermaid
flowchart LR
    A[Idea / Business Need] --> B[Technical Planning]
    B --> C[Architecture]
    C --> D[Development]
    D --> E[Testing]
    E --> F[CI/CD]
    F --> G[Production Deployment]
    G --> H[Monitoring & Support]
````

We actively use modern engineering tools and AI-assisted development workflows, including:

* **Claude Code**
* **Cursor**
* AI-assisted refactoring and code review;
* automated development workflows;
* CI/CD automation;
* structured task planning;
* human review and engineering control.

AI helps us move faster — engineering discipline keeps the result reliable.
